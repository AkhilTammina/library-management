## Library Management System

A small Python project for managing books and library members.

## Features
- View, add, search and delete books
- Register, view and delete members
- Issue books to members
- Return issued books
- Save book, member and loan information in JSON files



## Run the project
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open the terminal in that folder.
4. Run:

   ```bash
   python main.py
   ```
